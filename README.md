# Relay website

This is the first Relay marketing website: a lightweight static landing page with no build tools or dependencies.

## Run it locally

Open `index.html` in a browser. The page is entirely self-contained except for the Google Fonts request.

## Deploy with Vercel

1. In Vercel, choose **Add New → Project** and import this repository.
2. Keep the framework preset as **Other** and leave the build command blank.
3. Click **Deploy**.

Before sharing the site publicly, replace the `hello@relay.bot` links in `index.html` with Relay's real contact or Discord invite URL.
